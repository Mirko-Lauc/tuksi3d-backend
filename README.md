## 🇬🇧 English

**Tuksi 3D Pro** is a comprehensive, cloud-deployed management and quoting backend designed specifically for 3D printing businesses. 

Built to solve real-world logistical and pricing challenges faced by printing services like Tuksi 3D, this project bridges
the gap between hardware operations and software efficiency. It provides an automated, precise, and scalable way to calculate production 
costs, manage filament inventory, and track client orders.

### Key Features
* **Live Quoting Engine:** Calculates precise production costs (material, electricity, wear-and-tear) and profit margins in real-time.
* **Inventory Management:** Tracks filament spools, automatically adjusting parameters based on material type and remaining grams.
* **Order Tracking:** Full CRUD operations for client orders, tracking status from "Pending" to "Completed".
* **Cloud Database:** Integrated with a permanent PostgreSQL database on Neon, ensuring data persistence across remote sessions.

### Tech Stack
* **Backend:** Python, FastAPI, SQLAlchemy, asyncpg
* **Database:** PostgreSQL (Hosted on Neon)
* **Frontend MVP:** HTML5, Tailwind CSS, Vanilla JS
* **Deployment:** Render (Web Service & Environment Variables)

## 🇪🇸 Español

**Tuksi 3D Pro** es un sistema integral de gestión y cotización desplegado en la nube, diseñado específicamente para emprendimientos y
granjas de impresión 3D.

Creado para resolver los desafíos logísticos y de fijación de precios que enfrentan los servicios de impresión reales como Tuksi 3D, 
este proyecto une las operaciones de hardware con la eficiencia del software. Proporciona una forma automatizada, precisa y escalable
de calcular costos de producción, gestionar el inventario de filamentos y hacer un seguimiento de los pedidos.

### Características Principales
* **Motor de Cotización en Vivo:** Calcula costos precisos de producción (material, electricidad, desgaste) y márgenes de ganancia en tiempo real.
* **Gestión de Inventario:** Rastrea bobinas de filamento, ajustando parámetros según el tipo de material y los gramos restantes.
* **Seguimiento de Pedidos:** Operaciones CRUD completas para trabajos de clientes, controlando el estado desde "Pendiente" hasta "Completado".
* **Base de Datos en la Nube:** Integrado con una base de datos PostgreSQL permanente en Neon, asegurando la persistencia de datos en sesiones remotas.

### Tecnologías Utilizadas
* **Backend:** Python, FastAPI, SQLAlchemy, asyncpg
* **Base de Datos:** PostgreSQL (Alojado en Neon)
* **Frontend MVP:** HTML5, Tailwind CSS, Vanilla JS
* **Despliegue:** Render (Web Service y Variables de Entorno)
